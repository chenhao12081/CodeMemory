# LangGraph 工作流

## 状态图

LangGraph 可以用 StateGraph 把模型调用、检索、工具执行和人工确认组织为节点与边。状态 Schema 明确节点之间共享的数据，普通边表达固定顺序，条件边根据状态选择下一步。compile 后的图可以通过 invoke 执行，也可以配置 checkpointer 保存线程状态。

## RAG 路由

RAG 工作流可以先判断用户问题是否属于知识库范围。范围内的问题进入检索节点，范围外的问题进入普通对话。检索完成后还可以增加证据充分性判断：资料足够时生成有依据的答案，资料不足时拒答或进入带明确标识的降级分支。

## 可评测的分支

工作流应在最终状态中显式记录 intent、retrievalStatus 和 answerMode，而不是通过答案文案反推执行路径。这样评测器可以分别计算意图准确率、证据判断准确率、最终分支准确率和端到端成功率，也能定位问题发生在检索、路由还是生成阶段。
