# Node.js SSE

## 为什么使用 SSE

大模型生成答案需要时间，服务端发送事件（SSE）可以通过一个长连接持续把文本片段推送到浏览器，让用户更早看到首个 token。SSE 基于普通 HTTP，浏览器支持 EventSource，适合服务器到客户端的单向事件流。

## 代理缓冲

SSE 响应应使用 text/event-stream，并保持连接与分块传输。经过 Nginx 等反向代理时，需要关闭代理缓冲和可能合并响应的缓存，否则服务端虽然持续写入，浏览器仍可能在缓冲区积累到一定大小后才一次收到。

## 连接清理

客户端断开后，服务端应监听请求关闭事件，取消上游模型生成并释放定时器、数据库连接或其他资源。生产实现还需要心跳、超时、并发限制和错误事件，避免长连接无限占用资源。
